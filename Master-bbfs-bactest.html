⚙️ Setup Google Drive Sync

Masukkan URL Google Apps Script Web App yang sudah Anda deploy. Belum punya? Klik tombol 📖 Panduan di toolbar backtest.

📖 Panduan Setup Google Drive Sync

Langkah 1: Buka Google Apps Script

Buka script.google.com → Login Google → Klik New Project.

Langkah 2: Copy Kode Berikut ke Code.gs

Langkah 3: Deploy Web App

  1. Klik Deploy → New deployment
  2. Klik ikon gear → pilih Web app
  3. Description: BBFS Backup
  4. Execute as: Me
  5. Who has access: Anyone
  6. Klik Deploy → Authorize access → Allow
  7. Copy Web App URL (akhiran /exec)

Langkah 4: Simpan URL

Klik ⚙️ Setup Sync di toolbar, paste URL, klik Simpan.

✅ Selesai!

Sekarang bisa klik ⬆️ Upload ke Drive untuk backup, dan ⬇️ Download dari Drive untuk restore di perangkat lain.
