Aplikasi ini bisa menampung banyak pasaran sekaligus dalam 1 file. Setiap pasaran punya data sendiri-sendiri — baris result, angka acuan, metode hitung, dan rumus khusus. Data antar pasaran tidak akan tumpang tindih.

➕ Tambah Pasaran Baru

🔄 Pindah Pasaran

🧮 3 Metode Hitung (Tab Rumus)

Metode hitung dipilih per pasaran. Jadi bisa beda-beda tergantung pasaran Bosq.

✖️ Perkalian
Rumus: Result × Angka Acuan
Contoh: Result 1234, Acuan 45673210 → 1234 × 45673210 = 56.361.141.140 → ambil digit unik.
➗ Pembagian
Rumus: Angka Acuan ÷ Result (dibulatkan ke bawah)
Contoh: Acuan 45673210 ÷ Result 1234 → 37012,65 → dibulatkan jadi 37012 → ambil digit unik.
√ Akar Kuadrat
Rumus: √(Result × Angka Acuan) (dibulatkan ke bawah)
Contoh: √(1234 × 45673210) = √56.361.141.140 ≈ 237403,88 → dibulatkan jadi 237403 → ambil digit unik.
⚙️ Cara Pakai Tab Rumus
  • Pilih Metode Hitung (Perkalian / Pembagian / Akar Kuadrat)
  • (Opsional) Isi Angka Khusus untuk pasaran ini. Kosongkan kalau mau pakai Angka Acuan Global.
  • Klik Simpan Rumus — BBFS & AI akan otomatis dihitung ulang.
  • Klik Reset Rumus Khusus untuk kembali ke acuan global.
🎯 Semua data auto-save! Setiap perubahan langsung tersimpan di browser. Kalau tutup dan buka lagi, data tetap ada.
⚠️ Penting:
Data disimpan di browser (localStorage), bukan di server. Kalau ganti HP/browser atau clear cache, data bisa hilang. Biasakan salin (copy) hasil result sebelum tutup browser.

📦 Default Pasaran

Waktu pertama kali dibuka, aplikasi memuat 3 pasaran default: HOKIDRAW, SINGAPORE, MACAU. Kamu bisa hapus atau tambah sesuai kebutuhan.

🔒 Kenapa Tidak Tumpang Tindih?

Semua data disimpan dalam satu objek dengan struktur per-pasaran:

  • data["HOKIDRAW"] → baris, result, rumus, metode HOKIDRAW
  • data["SINGAPORE"] → baris, result, rumus, metode SINGAPORE
  • data["MACAU"] → baris, result, rumus, metode MACAU

🧮 Cara Hitung Umum

  • BBFS 8D: Hasil hitung → ambil digit unik (kiri ke kanan) sampai 8 digit
  • AI Jitu 5D: 5 digit terakhir dari BBFS 8D
