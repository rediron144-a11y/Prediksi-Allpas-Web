☁️ Cloud Sync & Backup
Status: belum terhubung ke Google Drive.
⚙️ Pengaturan Google Drive API (klik untuk buka)
Cara setup (sekali saja):
1. Buka console.cloud.google.com → buat project.
2. Aktifkan Google Drive API.
3. Buat OAuth Client ID tipe Web application.
4. Di Authorized JavaScript origins, tambahkan URL tempat file ini dibuka (contoh: http://localhost atau https://domain-anda.com).
5. Salin Client ID ke kolom di atas → Simpan.

Data disimpan di folder tersembunyi appDataFolder milik aplikasi (tidak terlihat di Drive utama Anda).
Deterministik — hasil sama untuk input yang sama. Auto-save ke perangkat. Siap dipasang sebagai app (PWA).
