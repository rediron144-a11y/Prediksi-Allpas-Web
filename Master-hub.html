1. Kredensial Google API

Cara mendapatkan:
1. Buka console.cloud.google.com → buat project baru.
2. Aktifkan Google Drive API di menu Library.
3. Menu Credentials → Create Credentials → OAuth client ID → tipe Web application.
4. Tambahkan URL halaman ini ke Authorized JavaScript origins.
5. Copy Client ID & API Key ke form di atas, lalu simpan.
Data disimpan terenkripsi di scope drive.appdata (folder tersembunyi aplikasi).
